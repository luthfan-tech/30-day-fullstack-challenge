# 30-Day Full-Stack Challenge

First-year CSE student | Starting August 1, 2026

Building strong full-stack foundations in 30 days with a practical, day-by-day approach.

## Goal

- Learn HTML, CSS, JavaScript, React, Node.js, Express, MongoDB, networking, and databases.
- Build real projects and improve problem-solving.
- Maintain a consistent and meaningful GitHub streak.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, React
- **Backend:** Node.js, Express
- **Database:** MongoDB, SQL basics
- **Foundations:** Linux, networking, CS basics
- **Tools:** VS Code, Git, GitHub, Vercel, Render, MongoDB Atlas

## Topics Covered (Day 1 – Day 15)

- **Day 1:** HTML Basics + Semantic Structure (Portfolio start)
- **Day 2:** CSS Basics (Selectors, Box Model, Flexbox, Styling)
- **Day 3:** Responsive Design (Media Queries)
- **Day 4:** CSS Polish (Cards, Hover, Transform, Transitions)
- **Day 5:** JavaScript Introduction (Variables, `let`, `const`, `console.log`)
- **Day 6:** Functions + Basic DOM (`querySelector`, `textContent`)
- **Day 7:** Events (`addEventListener`, Click events)
- **Day 8:** Arrays, Objects, Loops (`for`, `for...of`)
- **Day 9:** Array Methods (`push`, `pop`) + Array of Objects
- **Day 10:** Creating Elements (`createElement`, `appendChild`, `innerHTML`)
- **Day 11:** Add & Remove Elements Dynamically
- **Day 12:** Built Basic Todo List (Add + Delete)
- **Day 13:** Improved Todo List (Complete task + Enter key)
- **Day 14:** Local Storage + Final Todo Improvements
- **Day 15:** React Introduction (Vite setup + First Component)
