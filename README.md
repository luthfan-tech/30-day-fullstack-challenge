# 30-Day Full-Stack Foundations Challenge

**Challenge period:** 1 August 2026 – 30 August 2026  
**Status:** ✅ Completed  
**Learner:** Lutfan Mohammed Asif · First-year B.Tech CSE student

A 30-day learning challenge focused on understanding how modern web applications are built—from frontend foundations to React, backend architecture, databases, authentication, deployment concepts, and secure-development practices.

> This challenge provided orientation and practical foundations, not full-stack mastery. My next phase is to deepen JavaScript first, then build React and backend projects independently.

---

## Goal

- Build practical foundations in HTML, CSS, JavaScript, React, Git/GitHub, and web-development workflows.
- Understand how frontend, backend APIs, databases, and authentication work together.
- Develop a security-aware mindset for building web applications.
- Produce documented learning artifacts and projects instead of relying only on tutorials.

## What I Practised

### Frontend Foundations

- Semantic HTML, forms, and page structure
- CSS selectors, box model, Flexbox, responsive design, media queries, hover states, transitions, and card layouts
- JavaScript fundamentals:
  - Variables and data types
  - Comparisons and conditionals
  - Functions, loops, arrays, and objects
  - DOM selection and manipulation
  - Events with `addEventListener`
  - Local Storage

### React Foundations

- Why React is used
- Components and props
- State with `useState`
- Rendering lists using `.map()`
- Controlled form inputs
- Basic component structure
- React Router basics
- Lifting state and passing functions as props
- Local Storage with `useEffect`

### Full-Stack Architecture

- Client-server model and request-response cycle
- APIs, endpoints, HTTP methods, and JSON
- Frontend vs backend responsibilities
- Node.js and Express concepts: routes, middleware, `req`, and `res`
- MongoDB vs PostgreSQL: document vs relational databases
- How frontend applications use `fetch()` to call backend APIs
- Why frontend code should not connect directly to a database
- CORS fundamentals

### Authentication and Security Awareness

- Authentication vs authorization
- Sessions, cookies, and JWT concepts
- Password hashing importance
- Backend input validation
- Environment variables and secret protection
- CORS awareness
- OWASP-inspired secure-development habits

### Modern Tool Orientation

- Next.js
- Tailwind CSS
- TypeScript
- Docker
- FastAPI and Django overview
